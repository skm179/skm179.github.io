Windows Device Enrollment

Hands-on lab documenting the enrollment and verification of Windows devices in Microsoft Intune.

Windows devices visible under Microsoft Intune → Devices → Windows devices.

Overview

Successfully enrolled two Windows devices in Microsoft Intune with different ownership types.

Device Managed By Ownership Compliance OS
BYOD-LAB-OCarter Intune Personal ✓ Compliant Windows
CORP-LAB-EMiller Intune Corporate ✓ Compliant Windows

Enrollment Verification

The devices are visible under Microsoft Intune → Devices → Windows devices .

The Intune console identifies the ownership type, operating system, OS version, primary user, compliance status, and device check-in information.

Key Observations

  • ✓ Both Windows devices are successfully enrolled and managed by Intune.
  • ✓ BYOD-LAB-OCarter is registered as a Personal device, representing the BYOD scenario.
  • ✓ CORP-LAB-EMiller is registered as a Corporate device, representing the company-owned scenario.
  • ✓ Both devices show a Compliant status.
  • ✓ The devices are reporting recent Last check-in times to Intune.
  • ✓ The Intune console successfully identifies the ownership type, operating system, OS version, primary user, and device check-in status.

Result

Windows device enrollment was successfully completed for both Corporate and BYOD devices.
