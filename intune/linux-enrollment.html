Linux / Ubuntu Enrollment

Hands-on lab documenting the enrollment and verification of an Ubuntu Linux device in Microsoft Intune.

1 / 2
Ubuntu device showing the Intune compliance status.

Overview

Successfully enrolled an Ubuntu Linux device in Microsoft Intune and verified that the device is being managed and reported as Compliant.

Ubuntu is a Linux distribution, so this enrollment is documented as Linux / Ubuntu device enrollment.

Enrollment Verification

The Ubuntu device was successfully enrolled and is visible in the Microsoft Intune admin center under Devices → Linux devices .

Device Managed By Ownership Compliance OS OS Version
CORP-LAB-DBrooks Intune Corporate ✓ Compliant Linux 26.04

Verification from Ubuntu

The Ubuntu device itself also shows the following information:

  • ✓ Status: Compliant
  • ✓ Operating System: Ubuntu
  • ✓ Ownership Type: Company
  • ✓ Manufacturer: VMware, Inc.
  • ✓ Last Checked: Successfully reported to the organization

The compliance message confirms that the device meets the organization's device and security requirements.

Key Observations

  • ✓ The Ubuntu Linux device is successfully enrolled in Microsoft Intune.
  • ✓ Intune identifies the operating system as Linux.
  • ✓ The device is classified as Corporate ownership.
  • ✓ The device is managed by Intune.
  • ✓ The device is reporting a Compliant status.
  • ✓ The compliance status is visible both on the Ubuntu device and in the Intune admin center.
  • ✓ The device is successfully communicating with Intune, as shown by the recent last check-in time.

Result

Linux / Ubuntu device enrollment was successfully completed and verified in Microsoft Intune.
